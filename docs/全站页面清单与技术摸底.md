## 一、系统架构总览

```
用户 → Nginx (443) 
       ├─→ Platform 8083/8084 (前端页面/CMS/商城/API v1)
       ├─→ Auth-Center 8081 (登录注册/订阅/后台管理/抖音小程序)
       └─→ Captcha-Service 8090 (拼图验证码)
                ↓
              SQLite (data/easykai.db)
```

| 服务 | 端口 | 代码目录 | 职责 |
|------|------|---------|------|
| **Platform** | 8083/8084 | `platform/` | 前端页面渲染、CMS内容管理、商城、API v1 |
| **Auth-Center** | 8081 | `auth-center/` | 登录注册、订阅管理、管理后台、抖音小程序 |
| **Captcha** | 8090 | `captcha-service/` | 拼图验证码 |
| **WeCom** | 5000 | `wecom-service/` | 企业微信通知转发 |

**模板引擎**：Flask Jinja2，后端渲染 + 少量前端JS交互（订阅/商城支付弹窗）
