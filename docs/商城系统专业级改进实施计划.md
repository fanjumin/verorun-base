## 阶段一：商品多图上传 + 富文本 + 导航入口（紧急）

### 1.1 数据库变更

**products 表** 新增字段：
- `images TEXT DEFAULT '[]'` — 多图JSON数组 `[{id, url, sort_order}]`
- `description` 字段已有，仅前端改为富文本

### 1.2 后端新增端点 (shop_admin.py)

| 端点 | 方法 | 功能 |
|------|------|------|
| `/shop/products/upload-image` | POST | 上传图片，返回URL |
| `/shop/products/<pid>/images` | GET | 获取商品图片列表 |
| `/shop/products/<pid>/images/<idx>` | DELETE | 删除单张图片 |
| `/shop/products/<pid>/images/reorder` | POST | 图片排序 |

### 1.3 前端改造 (admin.html)

- 商品表单：缩略图URL → 多图拖拽上传（预览+排序+删除）
- 描述：textarea → Quill 富文本编辑器（已引入Quill但未使用）
- 导航：添加"阿里巴巴API"入口
- 商品列表：增加图片缩略图列

### 1.4 文件存储

- 路径：`platform/static/products/`
- 命名：`{product_id}_{timestamp}.{ext}`
- 访问：`/static/products/{filename}`
- 限制：5MB, jpg/png/gif/webp

## 阶段二：SKU/规格系统

### 2.1 数据库新增表

**product_specs**（规格名）
```sql
CREATE TABLE product_specs (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    product_id  INTEGER NOT NULL REFERENCES products(id),
    spec_name   TEXT NOT NULL,       -- 如 "颜色", "尺寸"
    sort_order  INTEGER DEFAULT 0,
    created_at  TEXT DEFAULT (datetime('now','localtime'))
);
```

**product_spec_values**（规格值）
```sql
CREATE TABLE product_spec_values (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    spec_id     INTEGER NOT NULL REFERENCES product_specs(id),
    spec_value  TEXT NOT NULL,       -- 如 "红色", "XL"
    sort_order  INTEGER DEFAULT 0,
    created_at  TEXT DEFAULT (datetime('now','localtime'))
);
```

**product_skus**（SKU库存）
```sql
CREATE TABLE product_skus (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    product_id  INTEGER NOT NULL REFERENCES products(id),
    sku_code    TEXT NOT NULL,       -- SKU编码, 如 "R-001-RED-XL"
    spec_path   TEXT NOT NULL,       -- JSON: {"颜色":"红色","尺寸":"XL"}
    price       REAL NOT NULL DEFAULT 0,
    stock       INTEGER DEFAULT 0,
    image       TEXT DEFAULT '',     -- 规格专属图片
    is_active   INTEGER DEFAULT 1,
    created_at  TEXT DEFAULT (datetime('now','localtime')),
    updated_at  TEXT DEFAULT (datetime('now','localtime'))
);
```

### 2.2 后端API

| 端点 | 方法 | 功能 |
|------|------|------|
| `/shop/products/<pid>/specs` | GET | 获取规格列表 |
| `/shop/products/<pid>/specs` | POST | 添加规格名 |
| `/shop/products/<pid>/specs/<sid>` | PUT | 修改规格名 |
| `/shop/products/<pid>/specs/<sid>` | DELETE | 删除规格 |
| `/shop/products/<pid>/specs/<sid>/values` | POST | 添加规格值 |
| `/shop/products/<pid>/specs/values/<vid>` | PUT | 修改规格值 |
| `/shop/products/<pid>/specs/values/<vid>` | DELETE | 删除规格值 |
| `/shop/products/<pid>/skus` | GET | SKU列表 |
| `/shop/products/<pid>/skus/generate` | POST | 根据规格组合自动生成SKU |
| `/shop/products/<pid>/skus/<skuid>` | PUT | 修改SKU价格/库存 |
| `/shop/products/<pid>/skus/<skuid>` | DELETE | 删除SKU |

### 2.3 前端UI

- 规格管理面板（规格名+值输入，动态添加/删除）
- SKU矩阵生成器（规格笛卡尔积自动生成所有SKU组合）
- SKU列表（批量编辑价格和库存）

## 阶段三：多级商品分类体系

### 3.1 数据库新增表

```sql
CREATE TABLE categories (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL,
    slug        TEXT UNIQUE,
    parent_id   INTEGER DEFAULT 0 REFERENCES categories(id),
    level       INTEGER DEFAULT 0,      -- 0=顶级, 1=二级, 2=三级
    icon        TEXT DEFAULT '',
    sort_order  INTEGER DEFAULT 0,
    is_active   INTEGER DEFAULT 1,
    created_at  TEXT DEFAULT (datetime('now','localtime')),
    updated_at  TEXT DEFAULT (datetime('now','localtime'))
);
```

**products 表** 修改：`category TEXT` → 使用 `category_id` 关联

### 3.2 后端API

### 3.3 前端UI

## 阶段五：AI 大模型融合 — 智能商品优化（新增）

> 复用系统现有 AI 引擎（`ali_api/services/ai_processor.py`），无需额外 API Key 配置

### 5.1 后端新增端点 (shop_admin.py)

| 端点 | 方法 | 功能 |
|------|------|------|
| `/shop/products/<pid>/ai-optimize` | POST | **全量优化**：标题多版本+描述重写+卖点+标签 |
| `/shop/products/<pid>/ai-title` | POST | 标题多版本生成（专业型/吸引力型/简洁型） |
| `/shop/products/<pid>/ai-description` | POST | 描述营销优化重写 |
| `/shop/products/<pid>/ai-features` | POST | 自动提取商品卖点 |
| `/shop/products/ai-batch` | POST | **批量优化**：一次处理最多20个商品 |

### 5.2 标题优化能力

AI 基于商品标题 + 类目 + 描述，生成 3 个不同风格版本：

| 风格 | 用途 | 示例 |
|------|------|------|
| **专业型** | 搜索引擎排名、B端采购 | "2024新款智能手机 6.7英寸大屏 5000mAh长续航 128GB存储" |
| **吸引力型** | 营销推广、首页推荐 | "超长续航旗舰手机！6.7英寸大屏+5000mAh+128G 仅需XXX" |
| **简洁型** | 列表展示、移动端 | "大屏长续航智能手机 128GB" |

### 5.3 描述重写能力

- 保留核心信息不变
- 优化段落结构和可读性
- 突出产品卖点和差异化优势
- 符合电商平台展示规范

### 5.4 卖点自动提取

从商品描述和规格中自动提取 3-5 个核心卖点，格式化为列表展示。

### 5.5 批量优化

- 选择多个商品一键优化
- 支持按类型（标题/描述/卖点）分别处理
- 结果预览后可逐条确认再保存

### 5.6 管理后台前端

**商品编辑表单**（每个字段旁有 🤖 AI 按钮）：
- 标题输入框旁 → 🤖 按钮 → 弹出 3 个标题选项供选择
- 描述区旁 → "🤖 AI优化描述" 按钮 → 自动替换为优化版本
- 卖点文本框旁 → 🤖 按钮 → 自动生成卖点填充

**批量操作入口**：
- 商品列表顶部 "🤖 批量AI优化" 按钮
- 弹窗选择优化类型（标题/描述/卖点/全部）
- 显示每个商品的优化进度和结果

### 5.7 AI 引擎复用架构

```
admin.html (AI按钮)
    ↓
shop_admin.py (AI API端点)
    ↓
ali_api/services/ai_processor.py (复用现有AI引擎)
    ↓
agent_matrix/engine.py (统一AI引擎，支持DeepSeek/DashScope/OpenAI)
    ↓
AI Provider API (DeepSeek / DashScope / OpenAI)
```

- 依赖系统已配置的 AI API Key（DashScope/DeepSeek 均可）
- 无需额外配置，复用 `ali_api` 的 `AIProcessor`
- 后台通过 `agent_matrix.engine.AIEngine` 统一调用
