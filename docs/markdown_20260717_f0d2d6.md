# VeroRunSystem 模块化订阅与防盗版设计方案

**文档版本**：`v3.0`
**适用架构**：BYOK（自带 LLM Key）+ 模块化订阅（AI 底座 + 站点生成 + 小程序 + 社媒发布等插件）
**核心原则**：LLM 算力用户自备，系统权益按模块授权；盗版可复制代码，但无法伪造授权令牌。

---

## 一、 订阅模型定义

系统将商业能力拆解为 **1 个免费底座 + N 个付费插件模块**：

| 层级 | 模块名称 | 核心功能 | 授权方式 |
| :--- | :--- | :--- | :--- |
| **免费核心** | **AI 底座 (Athena Core)** | 基础对话、单轮推理、系统设置 | 内置永久免费（但限制并发） |
| **付费插件 A** | **Site Builder Pro** | LLM 一键生成多页面品牌官网 + 设计令牌 | 独立订阅 / 按年授权 |
| **付费插件 B** | **Mini-App Generator** | 生成抖音/微信小程序前端代码及配置 | 独立订阅 / 按年授权 |
| **付费插件 C** | **Social Media Suite** | 微博/抖音/头条多平台一键内容分发 | 独立订阅 / 按年授权 |
| **付费插件 D** | **E-Commerce Plus** | 1688 供应链采集、高级促销引擎 | 独立订阅 / 按年授权 |
| ... | ... | ... | ... |

---

## 二、 防盗版核心设计：基于 JWT 的模块化 License

传统的“用户名+密码”或“单文件密钥”极易被复制。我们采用 **JWT (JSON Web Token) + RSA 非对称签名**，将用户购买的模块列表直接写入令牌中。

### 2.1 License 数据结构（Payload 示例）

```json
{
  "iss": "VeroRunSystem Official",
  "sub": "user_12345",
  "license_id": "L-2026-001",
  "exp": 1735689600,  // 授权到期时间戳
  "quota": {
    "total_sites": 3,        // 允许生成站点总数
    "total_miniapps": 5,     // 允许生成小程序总数
    "daily_posts": 50        // 社媒每日分发上限
  },
  "features": {
    "site_builder": true,    // 站点生成
    "mini_app": true,        // 小程序生成
    "social_push": false,    // 社媒发布（未购买）
    "ecommerce_plus": true   // 高级电商
  },
  "signature": "RSA_SHA256(header+payload+private_key)"
}
