## 一、核心定位重构

### 1.1 我们不是"又一个建站平台"

**核心定位**：
> **「AI矩阵驱动的智能商业运营平台」**
>
> 不只是建站 —— 是让AI矩阵帮你运营网站、生产内容、接待客户、管理电商、自动发布的智能系统。

**一句话解释**：
> 其他建站平台给你一个"工具"自己干活。
> 易站AI 给你一群"AI智能体"帮你干活。

### 1.2 与传统建站平台的本质差异

| 维度 | Wix / 凡科 / 阿里云 | Shopify / 有赞 | 易站AI |
|------|-------------------|---------------|--------|
| **核心能力** | 可视化拖拽建站 | 电商交易 | **AI矩阵编排** |
| **建站之后** | 自己维护/更新 | 自己上架/发货 | 智能体自动内容+客服+运营 |
| **内容生产** | 自己写/外包 | 自己拍/上传 | 内容工厂自动采集→AI加工→发布 |
| **客服** | 无/人工 | 无/人工 | AI智能体 7x24 + 知识库 RAG |
| **获客方式** | 被动等客户 | 平台流量 | AI 筛选意向 → 飞书通知销售 |
| **AI 能力** | 辅助工具(AI写文案) | 辅助工具(AI商品图) | **AI矩阵编排（6家AI供应商）** |

### 1.3 名词统一对照表

> **关键**：本方案所有英文术语统一为中国人能听懂的中文，已与抖音小程序保持一致的命名约定。

### 1.4 品牌名（待定）

当前抖音小程序已使用 **「智策AI建站」** 作为品牌名（AI客服系统提示词、服务页标题），但有以下选择：

| 备选品牌名 | 优势 | 劣势 |

## 二、真实能力全景

### 2.1 系统架构（实际运行）

```
用户访问 (网页端: easykai.cn / 小程序端: 抖音/头条)
    │

   │        │        │        │        │
   ▼        ▼        ▼        ▼        ▼
┌─────┐ ┌──────┐ ┌──────┐ ┌──────┐  ┌──────────────┐
│Platform│ │Admin │ │Auth  │ │Captcha│  │ 抖音小程序   │

└────┬──┘ └──────┘ └──────┘ └──────┘  └──────┬───────┘
     │         │                    │        │
     └─────────┴── auth-center ──────┘        │
                   Blueprint                  │
              (CMS/Shop/CF/User/              │
               Payment/Theme/                 │
               Knowledge/)                    │
                       │                      │
                       └── 共享同一数据库 ──────┘
                      (SQLite /data/easykai.db)
```

**关键架构特点**：
- 网页端 + 小程序端 **共享同一数据库**（`/data/easykai.db`）
- 同一知识库（knowledge_blocks）→ **网页AI客服和抖音AI客服共用RAG知识**
- 同一飞书Webhook → **网页端和小程序端的高意向客户都通知到同一飞书**
- **全渠道统一**: 一个客户从任何入口进来，系统识别到的是同一个人

### 2.3 系统的真正护城河

| 护城河 | 为什么竞品做不到 |
|--------|----------------|
| **AI矩阵编排** | 需要自建多供应商AI路由+任务分解引擎+自检重试机制，不是简单调个API就能做的 |
| **6家AI供应商统一接口** | DashScope/OpenAI/DeepSeek/OpenRouter/Ollama/SiliconFlow 统一切换，竞品通常只绑一家 |
| **内容工厂全链路自动化** | RSS→AI加工→多平台发布，不是单一功能，是完整Pipeline架构 |
| **知识库+数据清洗智能体** | 自动清洗数据→入库→RAG消费，全站AI功能共用一套知识 |
| **抖音小程序+网页端共享知识库** | 统一数据库、统一RAG、统一飞书通知，多端一个后台 |

## 四、产品矩阵与定价

### 4.1 核心定价逻辑

```
平台收费 = 软件授权费（建站/内容/AI客服/电商系统功能）
AI模型费 = 客户自理（自带 API Key）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
平台不卖Token、不赚AI差价、不承担API账单风险
```

**为什么这样设计**：
- 避免账单纠纷（客户用超了不会赖平台）
- 客户自由选择模型（DeepSeek/通义/硅基/GPT，想用哪个用哪个）
- 客户可随时更换供应商（不绑定任何一家）
- 平台零成本风险

**易站AI 有而竞品没有的能力**（真正独家）：

1. **AI矩阵编排** — 总调度智能体(Athena)自动分解任务 → 6家AI供应商并行执行 → 自检重试 → 结果汇总。没有任何建站平台有这个能力
2. **内容工厂 Pipeline** — RSS采集 → AI加工(通义千问) → 知识库入库 → CMS发布 → 社媒推送。一次性完成从信息输入到多平台输出
3. **知识库 + 数据清洗智能体** — 脏数据AI清洗 → 结构化知识库 → 全站RAG消费。一次搬运，全站AI受益
4. **6家AI供应商统一接口** — DashScope/OpenAI/DeepSeek/OpenRouter/Ollama/SiliconFlow，随时切换，不绑定任何一家
5. **抖音/头条小程序 + 网页端共享同一知识库 + 同一飞书通知** — 全渠道统一的AI客服系统

**竞品有而易站AI没有的**：
- 可视化拖拽建站（不影响AI平台定位）
- 海量模板库（5个主题 vs 竞品500+）
- 移动端独立适配
